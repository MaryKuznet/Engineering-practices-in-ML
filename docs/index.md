# Инженерные практики в машинном обучении

Данный проект демонстрирует **воспроизводимый ML‑пайплайн** с автоматической генерацией документации и отчетов об экспериментах.  
Работа выполнена в рамках **Домашнего задания 6: Документация и отчеты**.

Основная цель проекта — обеспечить возможность **полного воспроизведения результатов** любым пользователем (включая менторов) с минимальным количеством ручных действий.

---

## Что реализовано в проекте

- Воспроизводимый ML‑пайплайн
- Автоматическая генерация отчетов об экспериментах (Markdown + графики)
- Версионирование данных и артефактов
- Автоматическая генерация технической документации
- Публикация документации на GitHub Pages

---

## Быстрый старт (рекомендуется)

Для полного воспроизведения проекта достаточно выполнить **одну команду**:

```bash
pixi run repro
```

В результате будут автоматически выполнены следующие шаги:

1. Установка окружения и зависимостей (Pixi)
2. Загрузка данных с помощью DVC
3. Обучение и оценка модели
4. Генерация отчетов об экспериментах (Markdown + изображения)
5. Сборка сайта с документацией

---

## Основные компоненты проекта

### Документация
- Собирается с помощью **MkDocs + Material**
- Автоматически публикуется на **GitHub Pages**
- Обновляется при каждом изменении ветки `main`

### Отчеты об экспериментах
- Генерируются автоматически на основе результатов экспериментов
- Содержат:
  - сравнительные таблицы метрик
  - визуализации результатов
- Файлы отчетов:
  - `reports/experiments.md`
  - `docs/experiments/latest.md` (используется на сайте документации)

### Воспроизводимость
- Все шаги автоматизированы с помощью Pixi
- Подробные инструкции по воспроизведению
- Возможность полного прогона пайплайна одной командой

## Просмотр документации локально

Для локального просмотра сайта документации выполните:

```bash
pixi run docs
```

После этого сайт будет доступен по адресу:

```
http://127.0.0.1:8000
```

```

src/         # исходный код проекта
```

---

## Примечания для проверки

- Вся документация и отчеты генерируются автоматически.
- Ручные действия не требуются, кроме запуска указанных команд.
- При расхождениях результатов рекомендуется проверить:
  - корректность загрузки данных через DVC
  - использование окружения Pixi без ручных изменений
