# Использование проекта

В этом разделе описаны основные способы использования проекта и доступные команды.

---

## Основные команды

### Обучение модели
Запуск обучения и оценки модели:

```bash
pixi run train
```

При необходимости можно передать конфигурацию:

```bash
pixi run train -- --config configs/default.yaml
```

---

### Генерация отчётов об экспериментах

Автоматическая генерация отчёта в формате Markdown с таблицами и графиками:

```bash
pixi run report
```

В результате будут обновлены файлы:
- `reports/experiments.md`
- `docs/experiments/latest.md`

---

### Документация

Локальный предпросмотр сайта документации:

```bash
pixi run docs
```

Сборка документации (используется в CI):

```bash
pixi run docs-build
```

---

## Полный воспроизводимый прогон

Рекомендуемый способ запуска всего пайплайна:

```bash
pixi run repro
```

Команда автоматически:
1. Загружает данные
2. Запускает обучение
3. Генерирует отчёты
4. Собирает документацию
