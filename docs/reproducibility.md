# Воспроизводимость

В данном разделе описано, как полностью воспроизвести результаты проекта.

---

## Шаги воспроизведения

### 1. Клонирование репозитория
```bash
git clone <repository_url>
cd <repository_name>
```

### 2. Установка окружения
```bash
pixi install
```

### 3. Загрузка данных
```bash
pixi run dvc pull
```

### 4. Обучение и оценка
```bash
pixi run train
```

### 5. Генерация отчётов
```bash
pixi run report
```

---

## Один командный запуск (рекомендуется)

```bash
pixi run repro
```

---

## Проверка результатов

После выполнения шагов должны появиться:
- обученные модели (если сохраняются)
- `reports/experiments.md`
- `docs/experiments/latest.md`

---

## Замечания

- Все шаги воспроизводимы
- Используется фиксированное окружение Pixi
- Данные версионируются с помощью DVC
